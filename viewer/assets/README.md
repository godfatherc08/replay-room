# Viewer assets

None. Players are a stylized figure built from smooth primitives at runtime (`src/players.ts`): a
near-white matte body with a team-coloured shirt and shorts, one shared mesh set thin-instanced 22×.
An earlier build loaded Kenney's CC0 *Mini Characters* model; it read as a brown voxel doll from the
broadcast camera, so it was removed in favour of the clean primitive figure.
